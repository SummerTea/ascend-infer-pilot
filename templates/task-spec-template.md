## 三、约束与边界

1. **输入/输出张量契约**：形状 / 布局 / 对齐要求；输出必须支持调用方**显存预分配传入**；热路径禁动态分配（框架自身缓存分配器除外）。
2. **UB / 共享内存预算上限**：严禁超过目标硬件物理上限；`BLOCK_M/N` 与 `num_stages` 需做自适应保护。
3. **图捕获兼容**：须可被 `npugraph_ex` / `TorchAir` 录制；内部严禁 GPU/NPU-CPU 同步、动态分配、动态控制流（否则图录制断裂）。
4. **累加精度铁律**：累加器必须显式 fp32（如 `tl.sum(x.to(tl.float32))` 或 `tl.dot` 默认 fp32），严禁低精度累加。
5. **五不准红线**：热路径同步 / 前向动态转权重 / 访存边界 / 低精度累加 / 测试弱化——见 [AGENTS.md](../AGENTS.md) §5。
